LANCELOT / VANE

声を聴かせて、
ランスロット！

ある任務にて魔物の前に飛び出したランスロット。
目の前の人を助けるのに夢中で、 背後から魔物が放った呪いに気づけなかった。

大好きな幼馴染を守るために身を投げ出したヴェインは、 呪いを全身に浴びてしまう。

それは、
一番大切な人の言葉が、よくわからなくなる呪い。

気絶から回復したヴェインは、 ランスロットの話す言葉だけが 虫食いのように聞こえるようになっていた。

――俺は絶対にあきらめない。
このままランちゃんの声がわからないなんて、いやだ。

ヴェインはランスロットの言葉に耳を傾け、 聞き取れない言葉をひとつずつノートへ記録していく。

いつかまた、お前の言葉を理解できるように。
あの日以来、暗い表情のままの幼馴染の笑顔を取り戻して―― 大好きだよ、と伝えるために。

HOW TO PLAY

プレイ方法

DECODE

あなたはヴェインとして物語を進めます。 ランスロットの言葉の一部は、意味の分からない記号として聞こえます。 記号を選択し、その意味を推測してノートへ記録してください。

ANSWER

ランスロットの言葉に対する返答を選びます。 一度選んだ返答は、その周回では変更できません。 選択は二人の関係と結末に影響します。

MEMORY

正しく解析した言葉は記録されます。 二周目以降では、その記憶を引き継いだ状態から物語を始めることもできます。

LOG

一度読んだ場面は、画面上部のLOGから読み返せます。 物語を進めながら過去の言葉を手がかりにしてください。

MEMORY

記憶の継承

過去の周回で正しく解析した言葉があります。
